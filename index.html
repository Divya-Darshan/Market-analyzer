Abstract

This project presents a web-based sales forecasting system that utilizes machine learning principles to predict future sales performance. By analyzing historical sales data, the system computes average growth rates and applies them iteratively to generate reliable short-term forecasts. The application provides an intuitive interface for data input, real-time prediction, and visual representation of results through interactive charts.

Introduction

Sales forecasting is a critical business function that enables organizations to make informed decisions regarding inventory management, resource allocation, and strategic planning. Traditional forecasting methods rely on manual analysis, which is time-consuming and prone to human error.

This project addresses these limitations by implementing a computational approach that automates the forecasting process. Using historical sales data as input, the system calculates month-over-month growth rates, computes their average, and projects future values — a technique inspired by time-series analysis methods commonly used in machine learning.

Methodology

The forecasting algorithm follows a three-step process:

  1. Data Collection: The user inputs monthly sales figures (minimum 5 data points) through the web interface.
  2. Growth Rate Computation: The system calculates the percentage change between consecutive months:Growth Rate = (Current Month - Previous Month) / Previous Month
  3. Prediction Generation: The average growth rate is applied iteratively to the last known value to forecast 3 future months:Predicted Value = Last Value × (1 + Average Growth Rate)
